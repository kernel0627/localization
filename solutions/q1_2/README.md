# 问题 1（2）：基于编号枚举与位置筛选的匿名发射机辨识

问题 1（1）建立了由已知发射机坐标和观测夹角求接收机位置的模型。本问中，FY00、FY01 仍然已知，新增信号的发射机编号未知。因此，除接收位置外，还需要确定匿名信号对应的编号。

采用**编号枚举与位置筛选方法**：将每个可能编号代入 1（1）的定位模型，求出符合角度观测的位置，再利用接收机接近自身理想位置的条件选择结果。在精确测角、偏差充分小等下述条件下，除 FY00、FY01 外，**再增加 1 架匿名发射机即可有效定位**。

## 1. 建模条件与待求量

沿用 1（1）的坐标系：FY00 位于原点，FY00 指向 FY01 为横轴正向，编队半径 $R$ 已知。接收机知道自身编号 $k$，其理想位置 $P_k^0$ 由编队排列确定，实际位置 $P=(x,y)$ 未知。各发射机均位于理想位置。

将新增的匿名信号记为 $U$，其编号记为 $q$。接收机能够区分 FY00、FY01 和 $U$ 三路信号，因此三组观测分别为 $\alpha_{01}$、$\alpha_{0U}$、$\alpha_{1U}$，配对关系已知。

| 内容 | 在模型中的作用 |
|:---|:---|
| 三组观测夹角 | 约束接收机可能的位置 |
| 自身编号与理想位置 | 在多个符合观测的结果中进行选择 |
| 发射机理想位置与已知半径 | 将编号转成坐标，提供定位的长度尺度 |
| 待求的匿名编号 $q$ 与接收位置 $P$ | 本问需要同时输出的结果 |

已知自身编号、信号配对和编队尺度是这一模型的使用条件。数值验证取 $R=100\,\mathrm{m}$；若没有长度尺度，纯角度观测只能确定相应的归一化位置。

## 2. 额外发射机数量的下界

只有 FY00、FY01 发射时，接收机仅获得一个夹角 $\alpha_{01}$。固定两架发射机后，满足这一夹角的接收位置构成等角圆弧。接收机在自身理想位置附近沿圆弧移动，仍可产生相同观测，因此位置不能唯一确定。

所以，至少需要增加 1 架发射机。下面构造增加一架时的求解方法，并说明其局部有效性。

## 3. 匿名编号与接收位置的联合求解

### 3.1 枚举合法的匿名编号

FY00、FY01 已知，接收机本身也不能作为本次发射机。因此，匿名编号属于 $\mathcal Q_k=\{2,\ldots,9\}\setminus\{k\}$，共有 7 种可能。

对每个 $q\in\mathcal Q_k$，暂定匿名发射机位于 FY$q$ 的理想坐标。此时，FY00、FY01、FY$q$ 三个发射点的位置全部确定，本问便转化为一次已知编号的定位问题。

### 3.2 调用 1（1）计算位置候选

将该组发射机坐标与三组观测角输入 [1（1）的角度定位模型](../q1_1/README.md)，求出接收位置。这里沿用同一套角度方程：所求位置到三个发射点的连线夹角，应与观测逐一相符。

一个编号假设可能对应多个位置。将求得的位置代回角度方程，保留通过三组角度检验的候选，组成集合 $\mathcal C_q$。程序还通过等角圆交点补查局部求解可能遗漏的候选；相关公式与数值处理见 [验证记录](../../docs/q1_2/验证记录.md)。

这一步得到的是“假设编号—可能接收位置”的对应关系。错误编号也可能产生满足角度的位置，所以角度一致性本身不足以决定匿名身份。

### 3.3 根据接收机的理想位置选择结果

题目的“位置略有偏差”提供了进一步的选择依据：真实接收位置应接近自身编号对应的理想位置 $P_k^0$。因此，在全部编号的候选位置中，选择距 $P_k^0$ 最近的一项：

$$
(q^*,P^*)=
\underset{q\in\mathcal Q_k,\;P\in\mathcal C_q}{\operatorname{argmin}}
\lVert P-P_k^0\rVert.
$$

其中 $q^*$ 为匿名发射机的估计编号，$P^*$ 为接收机的估计位置。这里比较的是接收机偏离自身理想位置的距离。若不同结果在距离上并列，或退化解可能影响最近结果，程序报告无法唯一确定。

由此，1（1）负责在给定编号后求位置，1（2）负责组织 7 次编号假设并选择身份与位置。整个求解过程只使用观测和已知编队信息，真实匿名编号不参与计算。

## 4. 增加一架的局部充分性

这一方法成立，需要分别说明不同编号能够区分，以及正确编号下的接收位置能够确定。

**编号的可区分性。** 先固定接收机的理想位置。九等分圆周中不存在与 FY01 径向相对的圆周编号，所以接收机指向 FY00、FY01 的方向不共线。匿名信号与这两个已知方向的夹角共同确定其方向；从圆周上的接收点沿这一方向出发，与编队圆最多再交于一个其他点，因此匿名编号唯一。

于是，7 个编号在理想接收位置产生的角度向量两两不同，具有正的最小间隔。由于角度随位置连续变化，可以选取同一个足够小的邻域，使每个编号的角度向量相对其理想值的变化均小于该间隔的三分之一。这样，不同编号即使采用邻域内不同的接收位置，也无法产生相同观测。

**位置的局部唯一性。** 正确编号确定后，$\alpha_{01}$ 与 $\alpha_{0U}$ 分别对应通过 FY00、FY01 和通过 FY00、FY$q$ 的等角圆弧。在理想位置，这两个圆均经过 FY00 和接收机，且不会重合；否则 FY01、FY$q$、接收机三个圆周点确定的编队圆还必须经过圆心 FY00，产生矛盾。足够小的偏差保持两圆不同及附近圆弧分支不变。两圆除公共发射点 FY00 外，附近仅有一个合法的接收位置交点。

将上述邻域取交集后，其中只有正确编号与真实位置这一组解，其他候选均位于邻域外。因此，真实偏差充分小时，最近候选规则能够选出真实解。结合额外 0 架不足，得到 $m_{\min}=1$。该论证给出邻域的存在性，尚未给出统一的偏差米数上限。

## 5. 算例：从编号假设得到定位结果

取 $R=100\,\mathrm{m}$，FY03 为接收机，真实匿名发射机为 FY05。借用题目表 1 中 FY03 的位置 $(112\,\mathrm{m},80.21^\circ)$ 生成精确观测，各发射机仍使用理想坐标。观测按 $(01,0U,1U)$ 排列，约为 $46.050^\circ$、$46.231^\circ$、$92.282^\circ$。

求解时隐藏 FY05 这一真值，依次代入 7 个合法编号。各编号下均存在符合观测的位置，最近候选到 FY03 理想位置的距离如下。

| 假设匿名编号 | 最近候选距 FY03 理想位置 / m |
|:---|---:|
| **FY05** | **12.01** |
| FY06 | 38.24 |
| FY04 | 51.46 |
| FY07 | 77.60 |
| FY02 | 115.95 |
| FY09 | 174.49 |
| FY08 | 206.07 |

FY05 对应的候选最近，算法选择匿名编号 FY05，并输出 FY03 的位置 $P^*\approx(19.044,110.369)\,\mathrm{m}$，与生成观测时的真值一致。此例展示了位置先验如何在多个角度一致的身份假设中完成筛选。表中距离、正文角度和坐标均经过舍入，计算使用完整浮点数据。

## 6. 实现验证及结论范围

验证覆盖 8 个接收机与各自 7 个匿名编号，每组位置条件共 56 个案例。真实编号和坐标只用于生成观测与评价结果。检查要求编号正确，且位置回代误差小于 $10^{-6}\,\mathrm{m}$。

| 接收位置条件 | 编号正确且位置通过检查 / 案例数 |
|:---|---:|
| 理想位置 | 56 / 56 |
| 表 1 接收位置 | 56 / 56 |
| 固定小扰动位置 | 448 / 448 |
| **合计** | **560 / 560** |

固定扰动由径向变化 $\{-5,0,5\}\,\mathrm{m}$ 与方位变化 $\{-1,0,1\}^\circ$ 组合，去掉零扰动，共 8 组。表 1 原用于问题 1（3），此处仅借用接收机坐标进行额外检查。

这些实验检验精确角度模型下的程序实现。观测由同一几何模型正向生成，约 $10^{-9}\,\mathrm{m}$ 的回代误差属于数值一致性结果；实际测角误差下的身份正确率和定位误差需要另行评估。560 个案例完整覆盖所选位置条件下的身份组合，空间覆盖仍是有限的。

因此，额外一架足够的依据是第 4 节的局部几何论证；算例说明选择过程，组合实验检验实现。详细候选记录、误差和复现步骤见 [验证记录](../../docs/q1_2/验证记录.md)。
