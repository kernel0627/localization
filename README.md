# Localization

本项目围绕 2022 年高教社杯全国大学生数学建模竞赛 B 题“无人机遂行编队飞行中的纯方位无源定位”，维护题面、分问解答、计算脚本、验证记录和可复现结果。

当前已经完成问题 1（1）的已知编号定位基线，以及问题 1（2）的匿名发射机辨识：枚举 7 个合法编号，复用 1（1）的角度模型，检查几何一致性并选择接近自身理想位置的候选。充分小偏差与精确测角条件下，除 FY00、FY01 外再增加 1 架发射机即可；1（2）的 560 个确定性案例均已通过。问题 1（3）和问题 2 尚未开始。

## 从哪里开始

1. 阅读 [`problem/B题.md`](problem/B题.md)，查看完整题面。
2. 阅读 [`solutions/q1_1/README.md`](solutions/q1_1/README.md)，查看问题 1（1）的正式解答。
3. 阅读 [`docs/q1_1/验证记录.md`](docs/q1_1/验证记录.md)，查看数值实验、多起点候选和证据范围。
4. 阅读 [`solutions/q1_2/README.md`](solutions/q1_2/README.md)，查看额外 1 架的论证、身份枚举方法和完整例子。
5. 阅读 [`docs/q1_2/验证记录.md`](docs/q1_2/验证记录.md)，查看 560 个案例、候选补查与退化处理。

## 安装与运行

```bash
python -m pip install -r requirements.txt
python -m pytest
python scripts/q1_1/run_validation.py
python -m scripts.q1_2.run_validation
```

实验穷举全部 36 组圆周发射机组合和 252 个有效接收案例。默认对每个案例运行 200 次标准差为 $0.1^\circ$ 的独立高斯角度噪声试验，共 50400 次；固定随机种子为 20220904，结果写入 `outputs/q1_1/`。

问题 1（2）使用精确角度观测，穷举 56 个理想位置案例、56 个表 1 接收位置案例和 448 个固定扰动案例，共 560 例、3920 个编号假设，结果写入 `outputs/q1_2/`。局部充分性论证与有限实验的适用范围分别记录在解答和验证文档中。
