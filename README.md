# Localization

本项目围绕 2022 年高教社杯全国大学生数学建模竞赛 B 题“无人机遂行编队飞行中的纯方位无源定位”，维护题面、分问解答、计算脚本、验证记录和可复现结果。

当前已完成问题 1（1）的已知编号定位与问题 1（2）的匿名发射机辨识。1（2）在充分小偏差与精确测角条件下，除 FY00、FY01 外再增加 1 架发射机具有局部充分性，560 个确定性案例均通过。1（3）已完成本机双偏差迭代实现与表 1 仿真：最大位置误差在累计第 80 个测角时隙低于 2 cm，第 92 个时隙低于 1 cm，第 113 个时隙低于 1 mm；第 196 个时隙完成停止确认。该实验采用固定已标定 FY00/FY01、精确测角和精确相对极坐标执行，有限结果的适用范围见正式解答。问题 2 尚未开始。

## 安装与运行

```bash
python -m pip install -r requirements.txt
python -m pytest
python scripts/q1_1/run_validation.py
python -m scripts.q1_2.run_validation
python -m scripts.q1_3.run_adjustment
```

问题 1（1）实验穷举全部 36 组圆周发射机组合和 252 个有效接收案例。默认对每个案例运行 200 次标准差为 $0.1^\circ$ 的独立高斯角度噪声试验，共 50400 次；固定随机种子为 20220904，结果写入 `outputs/q1_1/`。

问题 1（2）使用精确角度观测，穷举 56 个理想位置案例、56 个表 1 接收位置案例和 448 个固定扰动案例，共 560 例、3920 个编号假设，结果写入 `outputs/q1_2/`。局部充分性论证与有限实验的适用范围分别记录在解答和验证文档中。

问题 1（3）以**累计测角时隙**说明调整进程。一个时隙指固定一组发射机完成一次测角、各接收机计算并同时执行各自指令：FY00、FY01 和两架辅助机同时发射，其余六架接收。四架同时发射计为一个时隙，六架同时调整也属于这同一个时隙。公开轮换表每 28 个时隙重复一次，周期用于组织发射顺序。

默认增益为 0.5，径向和角向单次限幅分别为 $5\,\mathrm{m}$ 与 $2^\circ$。表 1 的逐时隙记录给出：

| 累计测角时隙 | 最大位置误差 | 所处阶段 |
|---:|---:|:---|
| 0 | 12.0111 m | 初始队形 |
| 80 | 1.7805 cm | 首次低于 2 cm |
| 92 | 0.6506 cm | 首次低于 1 cm |
| 113 | 0.9253 mm | 首次低于 1 mm |
| 145 | 0.0518 mm | 最后一次非零移动后的状态 |
| 196 | 0.0518 mm | 完成停止确认，结束记录 |

三项精度门槛在首次达到后，后续记录均保持达标。这些门槛用于离线描述精度进展。控制器按本机估计与夹角残差进入保持，仿真还需确认完整轮换表内的接收决策均为保持；第 146～196 个时隙没有位置改变，其中第 169～196 个时隙构成完整的停止确认窗口。因此，应分别报告达到指定精度的时隙、最后移动时隙和停止确认时隙。

默认运行有 145 个时隙发生移动，共产生 850 次非零单机动作。早期角向误差会暂时增大，完整轨迹见 [逐时隙误差记录](outputs/q1_3/error_history.csv)。实际坐标用于仿真生成观测、模拟执行和离线评分，本机控制依据自身观测与已知编队信息。当前结果属于精确模型下的有限仿真，一般收敛性及测角、执行误差下的性能仍需研究。
