## 2. 为什么增加圆交点补查

仅从接收机理想位置对每个编号启动一次 1（1），已能正确完成表 1 的全部 56 例。但在这 392 次编号假设中，有 26 次局部求解遇到退化夹角异常。进一步做几何检查发现，其中 18 个假设仍然存在能解释观测的离散候选。因此，局部求解异常不能作为“这个编号无解”的证据；局部收敛到非零残差也不能证明全局无解。

最终实现保留 1（1）的原函数，并对每个编号补查两组等角圆的交点。这里利用了本问的无噪声、三个发射机、其中一个为圆心的结构。所有补查候选重新通过同一个 `pairwise_angles()` 函数验证三组观测角。

### 2.1 四组圆配对如何给出候选

先把坐标除以 $R$。令归一化接收位置为 $p$，两个圆周发射机坐标为 $a_1=(1,0)$、$a_q=(\cos\theta_q,\sin\theta_q)$。定义旋转算子 $J(x,y)=(-y,x)$。

固定端点 $0$、$a$ 与夹角 $\alpha\in(0,\pi)$ 后，可能的等角圆圆心为 $C_s(a,\alpha)=(a+s\cot\alpha\,Ja)/2$，其中 $s\in\{-1,+1\}$。圆半径为 $\lVert C_s\rVert$，故圆方程为 $\lVert p\rVert^2-2C_s^\mathsf Tp=0$。

分别使用 $\alpha_{01}$、$\alpha_{0U}$，得到两组圆心

$$
C=C_s(a_1,\alpha_{01}),\qquad
D=C_t(a_q,\alpha_{0U}),\qquad
(s,t)\in\{-1,+1\}^2.
$$

当 $C\neq D$ 时，两圆方程相减得到 $(C-D)^\mathsf Tp=0$。设 $v=J(C-D)/\lVert C-D\rVert$，除公共交点 $p=0$ 外，另一个交点直接为 $p=2(C^\mathsf Tv)v$。恢复实际坐标时乘以 $R$。

每个编号只有 4 组符号组合。剔除与发射机重合的点，并验证三组原始无向夹角。验证必须保留：整圆包含可能对应补角的圆弧，单凭落在圆上还不足以确定原观测角。合并重复点后，与 1（1）的局部候选一起进行距离比较。

这给出了非退化精确几何下的有限候选生成方式。实现仍使用浮点数，接近退化时保留显式诊断。

### 2.2 两圆重合时如何处理

当 $C=D$ 时，两个约束可能对应连续圆弧，不能通过上述第二交点公式处理。代码保留整圆到理想接收位置的距离下界

$$
b=R\left|\left\lVert P_k^0/R-C\right\rVert-\lVert C\rVert\right|.
$$

任何合法圆弧都包含在这个整圆上，因此其距理想位置的距离至少为 $b$。若当前最佳离散候选严格比所有这样的下界更近，仍可选择它；若连续分支可能更近或并列，则返回 `degenerate`。下界只用于保守排查，即使第三个角最终不允许某段圆弧，也不会据此误删可能的近解。

归一化圆心重合判据使用相对尺度 $10^{-10}$，距离下界留出浮点裕量。输入角为 $0$ 或 $\pi$ 的共线情形不属于当前圆公式接口，程序明确报错。本文局部论证和所有正式验证位置均避开这种情形。

## 3. 接口与选择状态

```python
import numpy as np
from scripts.q1_2.identification import identify_anonymous_emitter

result = identify_anonymous_emitter(
    receiver_id=3,
    observed_angles=np.deg2rad([
        46.050090886191015,
        46.23145171745684,
        92.28154260364785,
    ]),
    radius=100.0,
)
print(result.status)
if result.selected is not None:
    print(result.selected.emitter_id, result.selected.position)
```

本例输出 `selected`、编号 `5` 和约 `[19.04420117, 110.36901015]` 的坐标。

| 状态 | 含义 |
|---|---|
| `selected` | 最近的一致候选明确，连续分支距离检查也通过 |
| `ambiguous` | 最近的不同位置在距离并列容差内，未选择身份或位置 |
| `degenerate` | 连续解分支可能影响选择，未报告唯一定位 |
| `no_consistent_candidate` | 当前数值容差下没有通过三角度检查的候选 |

`hypotheses` 始终保留全部 7 个编号的诊断。`distance_margin` 比较最近两个离散位置，`identity_margin` 比较最佳候选与最近错误编号的离散候选；`continuum_distance_bound` 独立保存连续分支的距离下界。没有相应竞争候选时，字段为 `None`，CSV 中为空。

`selected` 表示算法按既定先验作出的选择。超出充分小偏差条件后，算法不能仅凭返回状态证明选择符合真实身份。

## 4. 验证设计

每个接收机编号 $k\in\{2,\ldots,9\}$ 对应 7 个真实匿名发射机编号 $q\neq k$，所以一个位置组完整覆盖 $8\times7=56$ 个案例。每例先由真实几何生成角度，然后只把接收机编号、角度和半径传入识别函数；真实匿名编号和真实坐标只在函数返回后用于评分。

| 位置组 | 位置定义 | 案例数 | 编号假设数 |
|---|---|---:|---:|
| `ideal` | 接收机的理想位置 | 56 | 392 |
| `table1` | 直接解析题面表 1 的接收机位置 | 56 | 392 |
| `fixed_offsets` | 径向变化 $\{-5,0,5\}\,\mathrm{m}$，方位变化 $\{-1,0,1\}^\circ$，去掉零／零组合 | 448 | 3136 |
| 合计 | 10 组位置条件下的全部身份组合 | **560** | **3920** |

三组实验均使用理想发射机坐标与精确观测角。表 1 在题面中属于 1（3），本次借用其中接收机坐标做独立检查，没有把其中的偏差位置用作本问发射机坐标。固定扰动点只是审查点，未假定随机分布，也未把它们当作“小幅偏差”的硬边界。

接受判据为编号完全正确、位置误差小于 $10^{-6}\,\mathrm{m}$；候选角度残差范数容差为 $10^{-8}\,\mathrm{rad}$。验证脚本若遇到任一案例不满足接受判据，会保留明细并以失败状态退出。
