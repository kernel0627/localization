# 问题 1（3）：随机初态、方向噪声与执行误差验证

本记录覆盖 505 次运行：100 个配对随机初态、五种条件，外加五次表 1 单独运行。算法与原停止阈值保持不变；表 1 单独运行不计入随机成功率。

## 实验可复现性

- 条件、初始抽样、种子、20 周期预算及四个源文件 SHA-256 见 [contract.json](../../outputs/q1_3/robustness/contract.json)。
- [trials.csv](../../outputs/q1_3/robustness/trials.csv) 含 505 行；每次运行还保存初态、末态、完整逐时隙误差与开销、停止状态、拟合失败数、首次厘米达标和运行时间。
- 每档相同的 100 个初态；单条方向标准差依次为 0、0.001、0.01、0.1 度；第五档为精确测角加 1% 相对径向/角向执行误差。没有通过独立污染六个冗余夹角来伪造噪声，也未将两类误差混施。
- 拟合失败保留失败位置，预算耗尽保留预算端点，成功率使用全部 100 次作为分母。表 1 单独标记 trial=-1，不进入随机比例。
- 分别记录停止、终态精度与联合成功。成功率 95% 区间用 Wilson 方法；分位数使用 NumPy 线性插值。配对档位不合并为独立样本。

## 局部噪声平台

固定名义参考分支的周期噪声协方差通过离散 Lyapunov 方程求得。矩阵方程相对残差约为 $2.18\times10^{-15}$，协方差正定；独立迭代传播也收敛到该解。比较统计量统一为周期端点的 $\sqrt{\mathbb E[E_{\mathrm{rms}}^2]}$。

- 测试验证零噪声下原轨迹不变、共享视线引起的夹角协方差、随机流复现、固定基准不动、失败运行保留在分母、无向角导数及周期协方差传播。无向角在 0 和 pi 的不可微情形明确拒绝。
- [validation.json](../../outputs/q1_3/robustness/validation.json) 独立核查 505 次运行的源文件哈希、初态配对、固定基准、由末态坐标重算的最大误差/RMS、由逐时隙记录重建的移动量和发射开销以及汇总统计。

## 结论

方向噪声导致持续误差波动，原有极小保持阈值在三个方向噪声档中均未完成停止确认；不得把预算耗尽写为收敛成功。改变停止阈值也不会自动改善位置精度。无噪声结果、随机初态证据及含噪限制均应结合各自的实验条件解释。

模型仍有明确局限：未给出连续初态区域的全局证明、噪声下真实误差的统一上界，且 1% 相对动作误差不覆盖固定偏置或持续漂移。这些是结论范围，不能写成已经证实的能力。
