# 双配置轮换随机与含噪验证：执行合同

本轮重点为 appendix1 双配置轮换互校法的随机初态、含噪数学模型和有限预算鲁棒性。固定调度为 $(0,1,4,5)$、$(0,1,7,8)$，比较增益 $0.5$ 与 $1$；保持原控制器、限幅及本机保持规则。预算统一为 560 个时隙，不根据本轮结果重新选调度或调参。

## 信息与执行边界

定位和控制仅使用本机当前无向夹角、编号、理想几何、公开调度及本机保持记忆。随机真值、链路偏置、执行误差由仿真器持有；评价可读取真值。径向/角向命令执行沿用原建模接口，实际位移及历史命令不进入定位。FY00、FY01 的校准状态和已知目标半径沿用原题设置。

## 数学工作

建立两相局部线性模型，分别求两个增益的白噪声周期协方差。执行误差采用独立零均值乘性噪声，构造二阶矩传播算子并检查周期算子的谱半径；求联合误差的稳态二阶矩。额外检查 5%、10% 执行误差的局部均方稳定性，仅标为理论应力检查。

固定链路偏置使用跨时隙共享的随机向量，求周期平衡响应及其总体协方差。明确区分单次运行的固定误差与多次抽样的总体均值。理论适用范围为理想点附近、分支保持、未限幅、活动控制状态；保持、分支切换与大扰动由非线性实验验证。

理论和经验统一比较 $\sqrt{\mathbb E[\mathrm{RMS}^2]}$，RMS 分母包含 FY01–FY09 的 9 架机。使用第 559、560 时隙的对应相位，报告样本数量；真值几何 RMS 与线性近似的区别明确标注。

## 统计与验收

逐条件报告停止率、终点厘米/毫米精度率、停止且达标率及 Wilson 95% 区间；单列拟合失败、预算耗尽。报告最大误差分布、首次达标、记录区间持续达标、测角时隙、累计发射机次、端点位移。未达标不以 560 代替首达时间。配对比较以独立 trial 为 bootstrap 单位，提供置信区间与有效配对数。

仅在原五种共同条件下与 main 已有样本比较；新增噪声条件不外推 main 结果。停止后的状态可保持用于有限时域轨迹汇总，但不得继续累计成本；失败轨迹不能补成成功。有限预算未停止不等价于永不停止，首次进入阈值不等价于随后一直满足。
