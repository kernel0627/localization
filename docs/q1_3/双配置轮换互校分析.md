# 双配置轮换互校法：局部、有限轨迹与小噪声分析

本分析固定两时隙轮换：第一时隙发射 FY00、FY01、FY04、FY05，第二时隙发射 FY00、FY01、FY07、FY08。它调用冻结的 `appendix1/optimize_schedule.py` 中的原本机控制器；新脚本只选择这两个公开配置，生成局部矩阵和事后评价。每个接收机的输入仍是**当前**本机测得的四条视线构成的夹角，以及自己的保持计数。真值位置、动作历史和其他接收机观测只在模拟器和离线评价中使用。

完整可复现命令如下。归档后 `appendix1` 是指向本地 scratch 归档的兼容链接，所以正式 Git 检出本身不携带 505 次冻结实验的细节。

```bash
conda run --no-capture-output -n agent python -m scripts.q1_3.analyze_two_configuration
```

源文件散列、冻结 505 次实验合同指纹和该信息边界记录在 [protocol.json](../../outputs/q1_3/two_configuration_analysis/protocol.json) 与 [source_hashes.json](../../outputs/q1_3/two_configuration_analysis/source_hashes.json)。当前合同指纹为 `ba2bc99beedf9c6111b8a43d88d12a5d02ea8c297916040ef69da952f99e55be`；本分析没有重跑随机批次，也没有重新选择调度或参数。

## 1. 两个分量是联合估计的坐标，不是两套定位器

对 FY02--FY09 记本机误差为 $e_i=(\delta r_i,R\delta\theta_i)$，其中 $R=100\,\mathrm m$，第二个量是米尺度的角误差。三个名义锚点的角度残差经同一个两变量最小二乘问题拟合，再同步给出径向和角向指令；随后两个指令分别限幅。这个表示法和限幅方式没有把问题拆成“先径向后切向”的两套算法。

固定名义最优参考对时，局部拟合为

$$
\widehat e_i=e_i+\sum_{j\in S\cap\{2,\ldots,9\}}B_{ij,S}e_j+O(\|e\|^2).
$$

完整的 $B_{ij,S}$ 见 [reference_error_blocks.csv](../../outputs/q1_3/two_configuration_analysis/reference_error_blocks.csv)。例如第一配置、FY02 对 FY04 的块中 $b_{rt}=0.253857$、$b_{tr}=0.831207$，都不为零；第二配置也保留这类交叉项。因此参考机的切向误差会影响接收机的径向估计，径向误差也会影响切向估计。

## 2. 局部持续反馈与径向/切向交叉传播

对每个时隙按照 main 的观测导数、唯一择优和 $K=J^+H$ 构造同步 $16\times16$ 矩阵 $M_1,M_2$，周期矩阵为 $A=M_2M_1$。状态顺序为 FY02 径向、FY02 切向，依此至 FY09，完整定义和逐时隙的择优裕度在 [nominal_selection.csv](../../outputs/q1_3/two_configuration_analysis/nominal_selection.csv)。最低相对择优裕度为 $2.7149\%$，所以在足够小的固定分支邻域内可以讨论该导数。

| 增益 $\eta$ | $\rho(A)$ | $\|A\|_2$ | $\|A^2\|_2$ |
|---:|---:|---:|---:|
| 0.25 | 0.750023 | 1.031498 | 1.034666 |
| 0.5 | 0.500022 | 1.105717 | 0.950807 |
| 1 | $3.91\times10^{-11}$ | 1.793969 | 0.265733 |

默认增益下两周期范数小于 $1$，支持固定分支、未限幅、持续修正映射在足够小邻域的局部收缩。增益 0.25 虽然谱半径小于 $1$，两周期范数仍略大于 $1$；本结果不据此给出同样的欧氏两周期收缩证明。增益 1 的近零特征值有重根和浮点敏感性，不能把表中的尾数当作高精度物理量。单周期范数可大于 $1$，说明局部瞬态放大仍可能出现。完整的谱、幂范数和矩阵在 [gain_stability.csv](../../outputs/q1_3/two_configuration_analysis/gain_stability.csv)、[cycle_power_norms.csv](../../outputs/q1_3/two_configuration_analysis/cycle_power_norms.csv) 和 `cycle_jacobian_gain_*.csv`。

把周期矩阵重排为全部径向分量后接全部切向分量。在默认增益下，四个块的算子范数 $(\|A_{rr}\|_2,\|A_{rt}\|_2,\|A_{tr}\|_2,\|A_{tt}\|_2)$ 为 $(0.830812,0.505288,0.424697,0.890340)$。纯切向输入的径向响应及纯径向输入的切向响应明确非零，完整三档数据见 [radial_tangential_blocks.csv](../../outputs/q1_3/two_configuration_analysis/radial_tangential_blocks.csv)。这回答了“main 原本已有径向/切向分量”为何不等同于解耦：坐标分量、联合估计和参考误差的交叉块同时存在，双配置只改变时间调度。

按 FY04、FY05、FY07、FY08 在前，其余 FY02、FY03、FY06、FY09 在后重排，周期矩阵右上块严格为零。默认增益中，其余四架每架自身 $2\times2$ 块均为 $0.25I$，最大误差为 $3.11\times10^{-16}$。这反映四个交替参考机形成闭合核心子系统；其余四机不反馈到该核心。该结构没有消除核心内部或其他机受核心驱动时的径向/切向交叉项，数值核验见 [core_subsystems.csv](../../outputs/q1_3/two_configuration_analysis/core_subsystems.csv)。

## 3. 原求解器中心差分交叉核验

为避免只用同一解析公式自证，对 16 个坐标方向的正负扰动经原 `decide_local_adjustment`、非线性最小二乘、择优和同步执行走完两个时隙。诊断中只移除保持记忆，以对应持续反馈的局部导数。三个增益乘三个步长 $10^{-3}$、$10^{-4}$、$10^{-5}\,\mathrm m$，共 $16\times2\times3\times3=288$ 个短周期探测。

所有探测均无分支变化、无限幅、无拟合失败。默认增益的相对 Frobenius 误差依次为 $3.57\times10^{-8}$、$9.47\times10^{-7}$、$1.30\times10^{-7}$；步长并非越小越可靠，求解器容差和浮点舍入都会进入差分。全部记录在 [cycle_difference_checks.csv](../../outputs/q1_3/two_configuration_analysis/cycle_difference_checks.csv)。

保持协议的状态还包含每台机自己的连续达标计数和 holding 标记。在所有机器均保持且未超过恢复阈值的区域，位置映射可为恒等映射。因此上面的 $A$ 只能解释持续修正核心，不能替代带有限容差保持协议的真实终态验证。

## 5. 两相位小噪声预测与冻结随机末态

固定名义分支、未限幅、无保持时，为每条视线加入独立的无穷小方向高斯噪声，再把对应注入协方差沿两个时隙传播。离散 Lyapunov 方程残差为 $3.08\times10^{-15}$，所得单位射线噪声方差响应的最小特征值为 $1304.40\,\mathrm{m}^2/\mathrm{rad}^2$；乘以以弧度计的射线噪声方差后得到位置状态协方差，均满足数值检查。

理论统计量在每相位均为 $\sqrt{\mathbb E[\mathrm{RMS}^2]}$，RMS 的分母固定为 9，不用中位数或最大误差代替。对 $0.001^\circ$ 每条视线噪声，预测相位 1、相位 2 分别为 $0.003691\,\mathrm m$、$0.003769\,\mathrm m$；$0.01^\circ$ 与 $0.1^\circ$ 按小噪声线性模型分别扩大 10 倍、100 倍，见 [phase_noise_predictions.csv](../../outputs/q1_3/two_configuration_analysis/phase_noise_predictions.csv)。

冻结的三个方向噪声档各有 100 个随机初态运行，均保留到 560 时隙。读取第 559、560 时隙的几何 RMS 后计算同一均方统计量，六项结果见 [noise_validation.csv](../../outputs/q1_3/two_configuration_analysis/noise_validation.csv)。例如 $0.001^\circ$ 的第二相位实测 $0.003789\,\mathrm m$、理论 $0.003769\,\mathrm m$，比值 $1.00531$；$0.1^\circ$ 第二相位为 $0.387002\,\mathrm m$ 与 $0.376933\,\mathrm m$，比值 $1.02671$。终态坐标还独立核对了第 560 时隙的几何 RMS。这些结果只说明固定分支小噪声统计量与冻结样本的关系；真实运行仍包括限幅、分支选择和保持。505 次完整实验中的失败、停止率和其他噪声条件保持原始记录，未被这一线性理论覆盖或重新计算。
