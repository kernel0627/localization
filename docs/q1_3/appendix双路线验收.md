# appendix 与 appendix1：研究结论与验收

日期：2026-09-05。两条路线分别保存在独立目录，主审制定信息条件、冻结实验方案并独立复算；GPT-5.6 Terra、high 子代理负责实现、实验与文档。本文集中说明论文可以采用的结论，详细算法与记录见 [appendix](../../appendix/README.md) 和 [appendix1](../../appendix1/README.md)。

## 1. 两条路线回答了什么

三发射启动有可行的局部反馈机制。FY02/FY05 交替把对方按理想参考拟合，能够在参考仍有偏差时逐步修正；FY02/FY09 则有不稳定误差模态。28 对扫描中 22 对局部稳定、6 对不稳定。每时隙的观测数量不足以决定总收敛开销，参考误差如何进入下一次反馈同样关键。

固定启动预算存在明显的初态与噪声限制。表 1 上 15 时隙可以把 FY02/FY05 都调整到厘米内，但冻结 A15/B6 对照在 100 个精确随机初态中只有 1 个终态达到全队厘米。A23/B6 提高到 99/100；依然不能将固定时钟结束写成“已在线证明双锚准确”。

main 的调度优化有更完整的本轮证据。固定交替使用 $\{0,1,4,5\}$ 与 $\{0,1,7,8\}$，沿用 main 的本机拟合、择优、增益、限幅与保持记忆，就能明显减少表 1 的首次精度达标开销。它同时缩小了有偏参考的反馈子系统，并增加了其余机的接收机会。其随机和含噪结果在下文按相同评价集列出。

## 2. 纯方位条件落实在哪里

每机动态输入为自己的当前夹角；appendix1 另保留本机保持记忆。编号、名义半径 $R=100\,\mathrm{m}$、准确固定 FY00/FY01 以及公开时隙表属于共同先验。待调机距离、实际位移、历史运动约束、其他接收机观测和坐标均不进入定位或控制决策。

输出径向与角向调整指令需要执行器假设。模拟器私有地执行动作、生成下一时隙角度及事后评分，控制器不读回执行位移。精确执行与 $1\%$ 相对执行误差是分别评价的条件；本文只对这个执行接口和 $R=100\,\mathrm{m}$ 的模型作结论。

主审构造的反例中，FY02/FY05 分别偏离约 5.32 cm、6.64 cm，而 FY02 当前三角几乎等于理想值，本机拟合为零。因此零估计、零三角残差不能单独认证双锚准确。两机联合角度的离线 Jacobian 满列秩，也不意味着每机掌握了联合信息。推导、数值秩、观测导数核验和实际反例坐标见 [信息条件审查](appendix信息条件审查.md)。

appendix1 的首次厘米发射机次减少约 66.3%，其时隙 31 的改善发生在本机保持之前。完整运行还受到确认周期由 28 缩为 2 的影响，所以完整停止降幅不能全部归因于定位迭代加速。两套 main 控制器的连续小估计计数都为 21。

## 4. 同一随机评价集

每种方法和条件均采用同一组 100 个随机初态，另列表 1。八架待调机径向偏差为 $U[-12,12]\,\mathrm{m}$，角向偏差为 $U[-0.3,0.3]^\circ$；该分布属于评价设计。噪声先加入视线方向再形成两两夹角，保留共享视线产生的角度相关性。种子、初态与源哈希均保存在合同中。

下表各精度率的分母均为 100；全部未达标样本保留在分母。A15/B6、A23/B6 分别固定执行 21、29 时隙，均完成既定时钟。main 与 appendix1 按本机保持语义记录结束，否则到 560 时隙耗尽预算。

| 条件 | main 终态厘米 | A15/B6 终态厘米 | A23/B6 终态厘米 | appendix1 终态厘米 | appendix1 完成保持 | appendix1 终态最大误差中位数 / P95 |
|---|---:|---:|---:|---:|---:|---:|
| 精确 | 100/100 | 1/100 | 99/100 | 100/100 | 100/100 | 0.00164 / 0.00210 mm |
| 方向噪声 $0.001^\circ$ | 78/100 | 0/100 | 40/100 | 99/100 | 0/100 | 6.144 / 9.026 mm |
| 方向噪声 $0.01^\circ$ | 0/100 | 0/100 | 0/100 | 0/100 | 0/100 | 62.021 / 90.795 mm |
| 方向噪声 $0.1^\circ$ | 0/100 | 0/100 | 0/100 | 0/100 | 0/100 | 0.619 / 0.907 m |
| 相对执行误差 $1\%$ | 100/100 | 1/100 | 99/100 | 100/100 | 100/100 | 0.00162 / 0.00215 mm |

精确档 main 与 appendix1 的首次厘米时隙中位数分别为 98、38；逐样本配对差值的中位数为减少 60.5 时隙。appendix1 完整停止时隙中位数为 90，较 main 的配对差中位数减少 106 时隙、424 发射机次。两个边际中位数之差与配对差中位数属于不同统计量。

三个方向噪声档的 main 与 appendix1 都耗尽 560 时隙，因此该停止协议下完整发射开销均为 2,240 机次，不能宣称含噪时已经节省完整无线开销。$0.001^\circ$ 档两者都在 100/100 轨迹中曾达到厘米，末态比例却分别为 78/100、99/100；首次达标与末态达标、持续达标、完成保持应分别报告。

appendix1 在带噪档的终态误差中位数较 main 更低，配对误差差值 P95 仍为正，表示优势并非逐样本成立。Wilson 95% 区间、全部分位数与首次事件配对分类保存在各目录的汇总表。例如 100/100 的 Wilson 区间约为 96.3%--100%，99/100 约为 94.6%--99.8%；有限样本成功不等于全域保证。

## 5. 失败机制与下一步研究顺序

bootstrap 的 `A23_B6/exact/trial_071` 中，新双锚分别剩余 7.382 mm、9.234 mm，FY04 却停在 10.138 mm。固定锚点的偏差被后续定位吸收，继续做 B 阶段调整形成同一误差平台。这给出了“双锚各自厘米内”不足以推出“全队厘米内”的实际反例。

论文可将 appendix1 作为主线调度改进候选，保留 appendix 作为少发射启动的探索与适用范围分析。下一步优先研究带噪条件下的本机保持规则，并将保持成功与终态精度共同评价。bootstrap 的后续改进可研究新锚残差传播、阶段 B 对准确 FY01 的参考使用和有限误差界；这些应另立协议，再评价，避免用当前测试样本反复调整预算。

两条路线均未证明任意初态的全局收敛，也未实现全队终止通信协议。公开固定时钟与本机保持具有明确的执行含义，模拟器汇总日志结束不应写成免费的在线全队共识。
