# 鲁棒性图的中文样式

正文重组后，使用 [两张论文组合图](../../figures/q1_3/paper/) 与 [独立生成入口](../../scripts/q1_3/build_paper_assets.py)。它们沿用下述字体、颜色和字号规范，宽度为 7.2 英寸、输出为 300 dpi PNG；旧 13 张图继续作为详细补充图。正文选图与资料关系见 [资料索引](资料索引.md)。

本轮重点调整 `report_two_configuration_robustness.py` 生成的五张图，并将 `plot_main_results.py`、`report_robustness.py`、`plot_two_configuration_results.py` 接入同一字体样式，共重新生成 13 张 PNG。图用于 A4 论文，采用 Matplotlib 静态绘图；从已有实验记录重新汇总、绘图，控制器和仿真参数保持原有设置。

| 图 | 要回答的问题与呈现方式 | 样本与解释 |
|---|---|---|
| 终点误差 | 两种增益在八类扰动下的精度如何；散点叠加中位数及 P05–P95 区间 | 每组 100 次随机试验；纵轴为对数，保留厘米阈值；精确条件的极小值属于数值残差 |
| 停止与达标率 | 精度达标是否伴随协议停止；分组柱及 Wilson 95% 区间 | 每组 100 次；分别给出停止、终点厘米达标、二者同时成立 |
| 配对停止时隙 | 同一初态改变增益会怎样影响停止开销；配对线图 | 精确条件的 100 对初态；表示完整停止所用时隙 |
| 理论与实验 | 局部理论是否匹配含噪统计量；双对数散点与逐点 bootstrap 95% 区间 | 共 24 个“噪声条件—增益—相位”组合；每点 100 次试验，匹配时隙 559、560 |
| 三方法比较 | main 与两种增益在共同条件下的精度、停止和发射开销如何；四面板组合图 | 仅五个共同条件，每组 100 次；首次厘米达标时隙与完整停止分别标明 |

中文实际使用项目中的思源黑体 Source Han Sans SC 2.005，包含 Regular 和 Bold 两个字重；英文和数字使用本机 Arial。共用入口为 `scripts/figure_style.py`，每次显式注册 `assets/fonts/source-han-sans/` 中的字体，缺文件时明确报错。字体从 Adobe 官方仓库下载，下载地址、版本及 SHA-256 见该目录的 `sources.json`，同时保留 SIL Open Font License。实际选用字体写入图像清单。

已通过渲染器的字符字体映射核对：中文常规/粗体分别为 Source Han Sans SC Regular/Bold，拉丁字母及数字为 Arial Regular/Bold。数学变量使用数学字体，单位用正体。中文与数学公式混排的标签显式指定思源黑体，以免 MathText 普通文字段出现缺字。

上述五张鲁棒性图宽以 7.2 英寸（约 18.3 cm）为双栏上限，单图为 5.8–6.2 英寸。多类别图上下排列，类别名换行，保证正文插图时可读。普通文字 9 pt、坐标轴 9.5 pt、刻度和图例 8.5 pt、面板标题 10 pt 加粗。建议按导出宽度插入，避免再次大幅缩小。较早的 main 与双配置组合图沿用各自面板尺寸，共用字体与基础样式；实际插入论文时仍需按目标宽度检查字号。

白底，去掉上、右边框；主线 1.3 pt、坐标轴 0.8 pt、辅助线 0.7 pt，网格浅灰。主要使用蓝色 `#0072B2`、橙色 `#D55E00` 与灰色，必要时加入青绿。柱状图结合纹理，散点结合不同符号，增益通过实心/空心或不同符号区分，支持灰度阅读。

默认输出 300 dpi PNG、五份绘图 CSV 和哈希清单。需要矢量图时运行：

```bash
MPLCONFIGDIR=/private/tmp/q13-mpl conda run --no-capture-output -n agent python -m scripts.q1_3.report_two_configuration_robustness --formats png pdf svg
```

省略 `--formats` 即只导出 PNG。清单仅列本次生成的图片与数据；以前生成的 PDF/SVG 不自动删除，也不计入本次清单。

验收包括：查看五张实际 PNG 的中文、刻度、图例和留白；检查缺字警告；比较改图前后全部绘图与统计 CSV 的哈希；运行现有报告核验脚本，复核数值、区间及理论比较。
