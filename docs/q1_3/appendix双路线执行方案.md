## 2. 共同信息条件

定位与本机控制的动态输入只能是该机当前夹角和自身保持记忆；已知编号、理想几何、半径 100 m、固定准确 FY00/FY01、公开时隙表是共同先验。禁止测距、实际执行位移、已知跨时隙运动约束和跨机观测/估计输入。禁止根据仿真真值切换、择优或停止。

指令是输出，实际位移是模拟器私有状态。定位不回读指令执行效果，也不靠命令积分推算状态。沿用 main 的相对径向与角向执行接口；精确执行只是理想档的仿真假设，1% 相对执行误差作为单独压力测试。只能据此说定位没有距离/位移观测输入，不能宣称全部运动学能力都由夹角题面保证。

方向噪声必须先扰动各条视线，再组合成无向夹角，复用 `SimulationNoise`。同一视线引起角度相关性，不能独立污染冗余三角/六角。噪声只在模拟器注入，不暴露随机误差真值给控制器。
