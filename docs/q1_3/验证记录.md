# 问题 1（3）：本机双偏差迭代验证记录

> 日期：2026-09-05。实际执行环境为 Conda agent，NumPy 1.26.4、SciPy 1.15.2。

## 1. 实现与信息范围

[local_adjustment.py](../../scripts/q1_3/local_adjustment.py) 实现单机偏差估计、参考组合择优和保持逻辑；[run_adjustment.py](../../scripts/q1_3/run_adjustment.py) 实现表 1 仿真和日志导出；[run_sensitivity.py](../../scripts/q1_3/run_sensitivity.py) 检查增益与有限初始扰动。

固定 FY00、FY01 为已标定基准，每时隙由 FY00、FY01 和 FY02～FY09 中的一对发射。辅助对按编号字典序公开轮换，28 时隙为一个周期。每架待调整无人机在一个周期中发射 7 次、接收 21 次。

单机决策接口接收本机编号、三个圆周发射机编号以及本机六个夹角。每个接收机拥有独立的控制器实例，仅维护自身连续合格次数与保持状态。实际坐标仅由仿真层用于生成观测、执行相对动作与离线评分。

每个时隙先冻结全体位置，为六架接收机分别产生夹角并调用各自控制器，然后同时执行六组位移指令。发射机在该时隙始终保持。

## 2. 二维偏差估计

取 $z=(\Delta r,R\Delta\theta)$ 为数值变量，使两个变量都具有米的尺度。第 $i$ 架的预测位置及坐标变换导数为

$$
P_i(z)=(R+z_1)
\begin{bmatrix}
\cos(\theta_i^*+z_2/R)\\
\sin(\theta_i^*+z_2/R)
\end{bmatrix},
\qquad
\frac{\partial P_i}{\partial z}
=\begin{bmatrix}
u_r & \dfrac{R+z_1}{R}u_\theta
\end{bmatrix}.
$$

其中 $u_r$、$u_\theta$ 是当前位置的径向与切向单位向量。角度残差和位置 Jacobian 复用 1（1），由链式法则得到 $J_z=J_P\,\partial P_i/\partial z$。三种参考对各自从 $z=0$ 启动一次最小二乘。

数值实现采用 trf，三个终止容差均为 $10^{-12}$，最大评估次数 100；计算范围为径向偏差 $\pm80\,\mathrm{m}$、角向偏差 $\pm60^\circ$。范围是局部求解的数值保护；没有据此证明整个区域可收敛。

接受候选要求求解器成功、三角度残差范数小于 $10^{-8}\,\mathrm{rad}$、未触及计算范围边界。几何异常的候选跳过；三种参考对全部失败时，本机在该时隙输出零位移并报告失败，清除保持标志和连续合格计数，仿真终止为 local_fit_failed。

临时参考机采用编号对应的理想坐标，所以发射位置偏差会传入估计。较小的三角度拟合残差只说明局部方程得到数值解，不能单独证明参考机准确。

## 3. 本机组合择优与动作

对每种参考对，用得到的位置预测本机对全部四个发射源的六个夹角，与本机实测值比较，得到一致性残差范数 $c_{i;ab}$。在理想队形预先计算该参考对的最小角度奇异值 $\sigma_{i;ab}$，使用

$$
S_{i;ab}=\frac{\sigma_{i;ab}}{1+c_{i;ab}/\tau},
\qquad \tau=10^{-3}\,\mathrm{rad}.
$$

选择分数最高的可用参考对，数值相同时按编号顺序决定。三个被拟合的夹角检验求解一致性，另外三个夹角提供第三发射机的交叉核验。$\tau$ 是评分尺度参数；当前实验没有把它当作传感器噪声标准差。

默认增益为 $\eta=0.5$，径向与角向指令同时由估计产生，单时隙分别限幅为 $5\,\mathrm{m}$ 与 $2^\circ$。仿真执行相对径向位移和绕 FY00 的相对角位移，假设方向跟踪、旋转正向约定和动作执行精确。执行器的极坐标状态由仿真层持有，控制器只提供相对命令。

## 4. 本机保持与结束记录

三项完整阈值依次为 $10^{-3}\,\mathrm{m}$、$10^{-5}\,\mathrm{rad}$ 和 $10^{-5}\,\mathrm{rad}$，分别检查估计径向偏差、估计角向偏差和六角一致性残差。

每架控制器连续 21 次自身接收观测均满足上述阈值的一半，才进入保持。21 次对应公开周期中该机能接收的全部配置。保持期间继续测角，任一指标超过完整阈值就恢复调整。这一规则给进入保持和恢复调整留出间隔，减少阈值附近的反复切换。

仿真在一个完整的 28 时隙周期内，所有接收决策均为保持时结束日志。该条件汇总本机动作状态用于仿真判定，未将其他飞机的夹角或位置传回单机控制器。实际持续运行时，各本机控制器仍可按自身观测恢复调整。

最大周期数默认为 20，达到上限后明确返回 max_epochs_reached，并由命令行入口失败退出。真实位置误差不参与这一停止条件。

## 5. 表 1 结果

默认参数下，仿真经历 7 个周期、196 个测角时隙，其中 145 个时隙有实际移动。累计产生 1176 次接收机决策、850 次单机非零动作，局部求解失败数为零；最后一个周期为全体保持的确认周期。

第一周期角向误差增大，体现了参考偏差在两个位置分量间的传递。后续周期两个分量均减小；有限数据未证明每时隙误差单调下降。

最终最大位置误差为 $5.18045\times10^{-5}\,\mathrm{m}$，均方根误差为 $2.75766\times10^{-5}\,\mathrm{m}$。这些是精确测角与精确执行仿真的结果，实际飞行精度需要结合传感与执行误差检验。

三组扰动采用随机种子 20220905，对八架待调整飞机的横纵坐标分别加入 $[-5,5]\,\mathrm{m}$ 均匀扰动，固定两架基准。理想队形没有非零移动；两周期用于本机连续观测合格与完整保持确认。

## 7. 自动测试与复现

全仓库 35 项测试通过，其中本机迭代新增 7 项：

1. 准确参考条件下，同时恢复径向和角向偏差。
2. 公开轮换的发射数量、组合唯一性及每架接收覆盖次数。
3. 三参考对的本机评分；改变未被该机观测的其他节点时，其决策保持相同。
4. 相对径向与角向执行、增益和步长限幅。
5. 连续 21 次本机观测后保持，以及超阈值后恢复。
6. 表 1 到达本机停止条件；每时隙发射机保持、初始数组不被修改、两基准固定、最后一个周期全部保持。
7. 最大周期上限和非法输入的显式处理。

运行依赖为 NumPy、SciPy；测试与静态检查使用 pytest、Ruff，均维护在根目录 requirements.txt。

    python -m pip install -r requirements.txt
    python -m scripts.q1_3.run_adjustment
    python -m scripts.q1_3.run_sensitivity
    python -m pytest -q
    python -m ruff check scripts tests
