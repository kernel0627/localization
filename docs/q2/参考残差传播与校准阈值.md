# 第二问：参考残差传播与校准阈值

本轮回答一个具体问题：FY01 先校准到什么程度，才足以支持其余 12 架的位置精度要求？沿用[三角基准调整](三角基准调整.md)的两阶段方法，用目标附近的误差传播给出阈值依据，再用有限残差和完整协议对照检查计算结果。

已经运行的结果支持将有限位置阈值作为阶段候选。在当前目标模板上，FY01 位置偏差向单个接收机定位偏差传播的最坏一阶倍率约为 $1.040833$。以全队最大误差 $0.01d$ 为**示例验收目标**，FY01 校准阈值 $0.005d$ 在本轮三个固定初态中有精度余量，并减少了非单位增益的校准开销。题目没有指定这个误差目标，因此它尚不构成最终默认参数。

分析入口为 [analyze_reference_residual.py](../../scripts/q2/analyze_reference_residual.py)，结果见 [summary.json](../../outputs/q2/reference_residual/summary.json)。本轮只研究精确测角下保留下来的参考位置残差；测角噪声、执行误差及全初态域保证仍未覆盖。

## 1. 参考残差如何进入接收机的位置估计

固定底边 $Q_{11}=(0,0)$、$Q_{15}=(4,0)$，FY01 的目标是 $C_0=Q_1=(2,2\sqrt3)$。实际校准结束位置写成 $C=C_0+\delta C$，随后保持不动。这里的 $\delta C$ 是实际参考位置与目标之间的偏差。在本轮精确测角、上侧正确分支条件下，两底角闭式反演给出 $\hat C=C$，因此可以用 $\lVert\hat C-C_0\rVert$ 作为在线校准条件。

接收机 $i$ 的真实位置为 $p_i$。观测来自实际参考点 $C$，定位器仍按目标参考点 $C_0$ 解释这些角度。记现有求解器选中的两条光滑角为 $H_i(p_i,C)$。在 $(Q_i,C_0)$ 附近定义

$$
J_i=\frac{\partial H_i}{\partial p_i},\qquad
B_i=\frac{\partial H_i}{\partial C},\qquad
G_i=J_i^{-1}B_i.
$$

$J_i$ 描述接收机移动对两条角度的影响，$B_i$ 描述 FY01 移动对同样两条角度的影响。它们都只含两条已经选定的光滑行；本轮没有将含有 $0$ 或 $\pi$ 退化行的完整三角 Jacobian 直接求逆。

由定位器满足 $H_i(\hat p_i,C_0)=H_i(p_i,C_0+\delta C)$，得到局部一阶关系

$$
\hat p_i-p_i\approx G_i\delta C.
$$

这个量是**位置估计偏差**。对于动作 $p_i^+=p_i-\eta(\hat p_i-Q_i)$，记实际位置误差 $e_i=p_i-Q_i$，则

$$
e_i^+\approx(1-\eta)e_i-\eta G_i\delta C,
\qquad e_i^*\approx-G_i\delta C.
$$

所以真实闭环终点的一阶偏差与定位偏差符号相反。对固定参考残差，减小增益改变靠近这个偏置终点的速度；它不能消除共同的参考偏差。上述关系在目标附近、所选角行光滑且定位器保持局部分支时适用，有限残差还包含高阶项。

## 2. 十二架接收机的传播倍率

采用矩阵谱范数，$\lVert\hat p_i-p_i\rVert_2\lesssim\lVert G_i\rVert_2\lVert\delta C\rVert_2$。每架的完整 $2\times2$ 矩阵及角行编号都保存在 [propagation_blocks.csv](../../outputs/q2/reference_residual/propagation_blocks.csv)。相同倍率可归纳为：

| 接收机 | $\lVert G_i\rVert_2$ | 解释 |
|---|---:|---|
| FY02、FY03、FY07、FY10、FY12、FY14 | 1.040833 | 本模板上最大的方向性传播倍率 |
| FY04、FY06、FY13 | 1.000000 | 最坏方向约等比例传播 |
| FY05、FY08、FY09 | 0.700000 | 目标附近最坏方向的传播较小 |

因此 $G_{\max}=1.0408329997$。这个最大值同时考虑了偏差方向，不能用八个离散探测方向中的最大数替代。最小接收机块奇异值为约 $0.315524\,\mathrm{rad}/d$；表内系数均在目标模板上计算。

例如 FY13 的矩阵为 $G_{13}=\operatorname{diag}(-1,0)$。FY01 向右偏一小段，位于底边中点的 FY13 会被估计到左侧；控制动作把 FY13 向右移动，最终产生同向的实际位置偏差。这个例子也核对了估计偏差和动作后偏差的符号。

## 3. 底角阈值与位置阈值的换算

在目标位置，两底角对 FY01 坐标的导数为

$$
J_C=\frac18
\begin{bmatrix}
-\sqrt3&1\\
\sqrt3&1
\end{bmatrix},\qquad
\sigma_{\min}(J_C)=\frac{\sqrt2}{8}\approx0.1767766953.
$$

若两底角相对目标的残差各自不超过 $\varepsilon$ 弧度，则目标附近有 $\lVert\delta C\rVert_2\lesssim8\varepsilon d$。这里的系数 $8$ 同时是 $J_C^{-1}$ 将角度无穷范数映射到位置二范数的精确线性算子范数。

直接计算组合映射 $G_iJ_C^{-1}$，得到其余 12 架的最坏一阶系数约为 $4.618802d/\mathrm{rad}$；全队还包括 FY01 本身，因此全队的对应系数仍取 $8$。将两个独立最大范数相乘会得到更松的上界，直接组合映射保留了方向关系。

| 每个底角残差 $\varepsilon$ | FY01 一阶位置上界 / $d$ | 其余 12 架最坏一阶位置上界 / $d$ |
|---:|---:|---:|
| $0.01^\circ$ | 0.0013963 | 0.0008061 |
| $0.05^\circ$ | 0.0069813 | 0.0040307 |
| $0.10^\circ$ | 0.0139626 | 0.0080613 |

这张表使用角度框内的线性最大值。另用闭式反演检查了每档的四个角度框顶点，见 [bootstrap_angle_box.csv](../../outputs/q2/reference_residual/bootstrap_angle_box.csv)；有限角度下存在高阶差异，表中数字不是非线性严格上界。

由于每轮已有两底角和闭式位置估计，有限校准候选直接采用 $\lVert\hat C-C_0\rVert_2\le\tau_C$。这样误差预算可直接用归一化位置单位表达，避免先把位置预算转换为较保守的角度阈值。含噪时 $\hat C-C_0$ 与实际参考残差不再相等，必须另外分配估计不确定度；本轮没有将此阈值推广到含噪运行。

## 4. 如何根据位置预算选择候选阈值

若分配给参考残差的下游位置预算是 $\tau_{\mathrm{ref}}$，一阶条件为 $G_{\max}\tau_C\le\tau_{\mathrm{ref}}$。对于包含 FY01 的全队误差，同时需要 $\tau_C$ 自身满足全队预算。由于本模板的 $G_{\max}>1$，前一条件在一阶上更严格。

以总位置目标 $0.01d$ 为例：若严格给参考传播分配其中一半，即 $\tau_{\mathrm{ref}}=0.005d$，则可先取 $\tau_C\le0.0048038d$。本轮将便于对照的 $0.005d$ 和 $0.01d$ 作为离散候选：前者的最坏一阶下游偏差约为 $0.0052042d$，后者约为 $0.0104083d$。因此 $0.01d$ 的参考阈值在最坏一阶方向上已经无法保证全队 $0.01d$ 目标。

本轮三个固定初态即使取 $\tau_C=0.01d$ 也通过了示例验收，这与上述判断一致：实际残差往往低于阈值，方向也不一定最坏。成功样例不能替代方向上界和非线性余量。$0.005d$ 可作为当前有限校准的阶段候选；正式阈值应随最终位置目标和误差预算确定。

若仅按 $d=50\,\mathrm m$ 展示，$0.005d$ 对应 $0.25\,\mathrm m$。纯角度观测没有据此恢复实际米制间距。

## 5. 已运行的小范围核验

### 导数与非线性反演

解析导数使用 $10^{-4}d$ 和 $10^{-5}d$ 两档中心差分核对。FY01 两底角、接收机位置角导数、参考位置角导数的最大绝对差分别为 $5.30\times10^{-11}$、$3.28\times10^{-9}$、$3.34\times10^{-9}$；将现有定位器返回的位置候选对 FY01 残差作差分，和 $G_i$ 的最大绝对差为 $7.15\times10^{-9}$ 以内。

对 $10^{-5}d$、$0.001d$、$0.005d$、$0.01d$、$0.02d$ 五档 FY01 残差，各取八个等间隔方向、全部 12 个接收机初始处于目标位置，共 480 次估计，完整三角检查全部接受。线性预测的最大绝对误差随残差量级变化如下：

| FY01 残差幅值 / $d$ | 最大线性预测误差 / $d$ |
|---:|---:|
| 0.00001 | $9.91\times10^{-11}$ |
| 0.001 | $9.92\times10^{-7}$ |
| 0.005 | $2.49\times10^{-5}$ |
| 0.01 | $1.00\times10^{-4}$ |
| 0.02 | $4.04\times10^{-4}$ |

这些数字呈现二阶余项的预期趋势，但只覆盖规定的离散探针，见 [residual_probes.csv](../../outputs/q2/reference_residual/residual_probes.csv)。

### 冻结残差后的主阶段

取 $0.005d$、$0.02d$ 两档残差，八个方向，增益 $1$ 和 $0.5$，共 32 个主阶段运行。保留原有两行定位、完整三角验收和 $10^{-8}\,\mathrm{rad}$ 在线停止。32/32 正常停止，最终真实位置偏差仍保留；例如 $0.005d$ 残差时，八方向中的全队最大终点误差约为 $0.0050285d$。

增益 $1$ 的主广播需要 4–5 槽，增益 $0.5$ 需要 19–23 槽。这些只统计**主阶段**，不包含前面的校准成本，不能与完整流程的 6 槽直接比较。具体状态和动作见 [main_stage_runs.csv](../../outputs/q2/reference_residual/main_stage_runs.csv) 和 [main_stage_observations.csv](../../outputs/q2/reference_residual/main_stage_observations.csv)。

这也说明在线目标角残差很小，不会自动消除参考形状带来的位置偏置。现有停止检查对这些样例可以正常工作，但精度结论仍需用实际位置误差离线验收。

所有完整协议均从动作日志重建了最终状态、累计端点位移与阶段成本。设校准观测轮数为 $n_C$、主广播次数为 $n_R$，则完整测角槽为 $2n_C+n_R$，发射机次为 $4n_C+3n_R$，两底角回传标量为 $2n_C$。累计端点位移另存，未解释为飞行路径长度或能耗；主阶段全队停止状态汇总仍有通信条件。

结果见 [threshold_comparison.csv](../../outputs/q2/reference_residual/threshold_comparison.csv)，逐例的初态标识、最终坐标、观测、动作与失败记录见 [threshold_cases.json](../../outputs/q2/reference_residual/threshold_cases.json)。原规则中与历史批次重合的 6 例，其全部汇总字段与原结果精确一致。

单位增益在无噪声、上侧正确分支、精确闭式反演和精确动作条件下一步消除 FY01 误差，所以本轮放宽阈值没有继续减少其 6 槽成本。增益选择在含噪条件下的权衡还需要另外验证。

## 6. 退化和分支检查

固定 FY01 横坐标为 $2$，将高度从 $2\sqrt3d$ 降到 $0.001d$。高度 $0.1d$、$0.01d$、$0.001d$ 时，底角位置 Jacobian 条件数分别为 20、200、2000；最小奇异值在最后一档约为 $0.000353553\,\mathrm{rad}/d$。这条对称路径显示了接近扁平三角形时的恶化，未穷举所有退化路径，见 [bootstrap_conditioning.csv](../../outputs/q2/reference_residual/bootstrap_conditioning.csv)。

另取每架接收机真位置为 $Q_i+(0.03,-0.02)d$，每架使用模板、两档局部初值、反射初值和上方远初值，共 60 次求解。51 次通过完整三角验收，接受结果均恢复了对应真位置；9 次失败，其中 4 次报告求解途中与发射机重合，5 次在数值终止后被完整三角残差拒绝。默认模板初值的 12 次全部通过。详见 [multistart_probes.csv](../../outputs/q2/reference_residual/multistart_probes.csv)。

这些检查保留失败作为局部分支证据。未发现错误位置被接受，不等于证明不存在其他解；FY01 两底角的上下镜像歧义也仍由既有上侧先验处理。

## 7. 复现与接续工作

```bash
conda run -n agent python -m scripts.q2.analyze_reference_residual
conda run -n agent python -m pytest -q tests/q2
```

本轮新增的有限校准入口为 `run_case(..., bootstrap_position_tolerance=0.005)`；原 CLI 和省略该参数时继续使用原角度规则。有限校准直接保存实际状态中的残差后进入主阶段，没有将 FY01 重置为目标。15 项 Q2 测试通过，覆盖原核心、传播导数、有限残差保留、在线与离线验收区分和非法阈值。其中专门替换角度估计结果，验证停止判断使用估计值，即使它与仿真真值不一致，也不会偷用真值改变在线判断。

Luna（xhigh）已独立审核传播符号、估计器输入边界、完整成本和失败分类，核对结果无实现级阻塞；上侧分支条件及上述输入边界回归检查已补齐。

下一批优先针对**位置预算驱动的阈值边界**：补最坏奇异向量方向的有限残差、附近少量接收机偏差以及主阶段终点误差，检查候选阈值的余量。以 $0.01d$ 为示例目标时，可把 $0.0048d$ 与 $0.005d$ 作小范围对照。全队目标精度确定后再选正式默认值；含噪停止与更多增益比较保持独立批次。
