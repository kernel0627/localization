# 两底角区间与参考位置预算

本说明把 FY01 的校准条件写成有明确几何含义的判据：给定两个底角的允许区间，计算所有可能 FY01 位置到目标的最大距离，再与参考位置预算比较。它补充[参考残差传播](参考残差传播与校准阈值.md)中的局部一阶关系，使有限角度区间本身也有精确的几何界。

实现为 [calibration_budget.py](../../scripts/q2/calibration_budget.py)，计算结果见 [summary.json](../../outputs/q2/calibration_budget/summary.json)。

## 1. 已知信息与待判断的量

规范底边为 $A=(0,0)$、$B=(4,0)$，目标顶点为 $C_0=(2,2\sqrt3)$。保持 FY01 位于底边上侧。已知真实底角满足 $\alpha\in[\alpha_-,\alpha_+]$、$\beta\in[\beta_-,\beta_+]$，并要求

$$
0<\alpha_-\le\alpha_+,\qquad
0<\beta_-\le\beta_+,\qquad
\alpha_++\beta_+<\pi.
$$

区间来源可以是无噪声观测相对目标的允许范围，也可以是观测值加已知的确定性误差界。若区间来自概率置信区间，以下几何结论在“真实角度落在区间内”这个事件上成立；统计覆盖率由另外的测量假设决定。

需要计算 $R_C=\sup\lVert C-C_0\rVert_2$，其中上确界取遍满足角度区间的所有上侧顶点。若 $R_C\le\tau_C$，便可确认该角度区间所允许的参考残差满足位置预算。

## 2. 为什么只需检查四个点

从 $A$ 观察 FY01，$\alpha$ 的上下界定义两个射线之间的凸角域。从 $B$ 观察时，两条射线的世界方向角为 $\pi-\beta_+$ 和 $\pi-\beta_-$，它们也定义一个凸角域。两个角域的交集是 FY01 的可行位置集合。

上述严格不等式保证四个交点均位于正向射线上，交集是有界凸四边形；零宽度区间对应线段或单点。它的四个顶点来自端点角度组合：

$$
V_{st}=F(\alpha_s,\beta_t),\qquad s,t\in\{-,+\},
$$

其中 $F$ 是原有两底角闭式反演：

$$
F(\alpha,\beta)=
\frac{4\sin\beta}{\sin(\alpha+\beta)}
\begin{bmatrix}\cos\alpha\\\sin\alpha\end{bmatrix}.
$$

任意可行点都可以写成四顶点的凸组合 $C=\sum_{s,t}\lambda_{st}V_{st}$，其中 $\lambda_{st}\ge0$ 且总和为 $1$。由三角不等式，

$$
\lVert C-C_0\rVert_2
\le\sum_{s,t}\lambda_{st}\lVert V_{st}-C_0\rVert_2
\le\max_{s,t}\lVert V_{st}-C_0\rVert_2.
$$

最大距离的顶点本身也属于可行集合，因此

$$
R_C=\max_{s,t}\lVert F(\alpha_s,\beta_t)-C_0\rVert_2.
$$

这是给定角度框内的精确几何最大值，不需要用一阶余项估计代替。实现遇到触及零角或允许角和达到 $\pi$ 的区间时明确拒绝，避免将这个有界四边形结论用于无界或退化情形。

## 3. 目标等边三角形附近的数值

令两角中心均为 $\pi/3$，各自半宽为 $\varepsilon$。一阶近似是 $R_C\approx8\varepsilon d$。四顶点方法给出的有限区间结果如下：

| 每个底角允许偏差 | 一阶位置界 / $d$ | 精确位置界 / $d$ |
|---:|---:|---:|
| $0.01^\circ$ | 0.0013962634 | 0.0013966856 |
| $0.05^\circ$ | 0.0069813170 | 0.0069918870 |
| $0.10^\circ$ | 0.0139626340 | 0.0140049853 |

在这三个数值例中，最远点是两角同时增大时的上顶点，其距离为 $2\tan(\pi/3+\varepsilon)-2\sqrt3$。实现仍检查全部四点，不依赖这个特例简化。

反求满足指定 FY01 位置预算的最大等半宽角度框，得到：

| FY01 位置预算 $\tau_C/d$ | 每个底角最大允许偏差 / rad | 每个底角最大允许偏差 / 度 |
|---:|---:|---:|
| 0.0020 | 0.0002498918 | 0.0143177448 |
| 0.0048 | 0.0005993770 | 0.0343417746 |
| 0.0050 | 0.0006243241 | 0.0357711342 |
| 0.0100 | 0.0012472989 | 0.0714649611 |

这些角度允许值描述真实角度范围。实际程序已有位置估计时，可直接按位置预算判断；角度区间判据用于把测量不确定度也计入锁定决策。

## 4. 与测角误差共同使用

假设底角观测为 $\tilde\alpha,\tilde\beta$，确定性测量误差分别不超过 $b_\alpha,b_\beta$。令真实角度区间为 $[\tilde\alpha-b_\alpha,\tilde\alpha+b_\alpha]$ 和 $[\tilde\beta-b_\beta,\tilde\beta+b_\beta]$，代入四顶点计算即可得到以目标为中心的 $R_C$。在线锁定条件为 $R_C\le\tau_C$。

因此，当前位置估计接近目标并不足以保证锁定：测量区间太宽时，仍存在超出预算的可能位置。反过来，当区间宽度已有可信界时，这个判据同时考虑了中心位置偏差和测量误差，无需用未知真值参与判断。

对于标准差为 $\sigma_\theta$ 的高斯测角情景，误差没有有限的确定性支撑，不能令 $b_\alpha=b_\beta=\sigma_\theta$ 后宣称必然覆盖。若在一个预先指定的静止批次中分别取 $K$ 个独立样本的均值，可通过明确的置信水平构造角区间，其半宽按 $1/\sqrt K$ 缩小。局部高斯位置椭圆的另一种近似见[测角误差与增益选择](测角误差与增益选择.md)。

FY01 的几何预算满足后，下游仍须计入参考误差传播、接收机自身测角误差和定位分支条件。这个精确底角界解决参考位置集合的界定；完整队形的误差预算由各部分组合。

## 5. 有限次统计查看的完整概率口径

预先规定最多查看 $M$ 次，将所有角区间至少一次失去覆盖的总概率预算记为 $\delta$。每个静止批次对两个底角分别取 $K$ 个独立同分布高斯测量的均值，单样本标准差 $\sigma_\theta$ 已知。给每角、每次查看分配 $\delta/(2M)$ 的双侧失覆盖概率，得到半宽

$$
b=\Phi^{-1}\left(1-\frac{\delta}{4M}\right)
\frac{\sigma_\theta}{\sqrt K}.
$$

由并集上界，预定最多 $M$ 次查看中的所有两角区间同时覆盖对应真实角度的概率至少为 $1-\delta$。角与角、查看与查看之间不要求独立；每个批次的均值分布和已知方差假设必须成立。若调整动作根据过去数据选择，新的静止批次在给定当前状态后仍需满足这个测量合同。这里固定 $K$ 和最大查看次数，没有对同一批数据任意反复改变样本数并套用单次区间。

在覆盖事件上，四边形给出真实 FY01 所在集合。仅当这个集合到目标的最大距离不超过 $\tau_C$ 时才锁定，就能在上述合同和上侧分支内控制误锁定概率。它比只比较均值反演点与目标更完整。

以 $\delta=0.01$、$\tau_C=0.0048d$ 为例，假设**测量均值恰在目标两底角**，使区间宽度足以满足预算的最小样本数如下：

| 单次底角标准差 | 一次预定检查的 $K$ | 该次检查测角槽 / 发射机次 | 最多 30 次查看、整体 99% 覆盖时每次的 $K$ |
|---:|---:|---:|---:|
| $0.01^\circ$ | 1 | 2 / 4 | 2 |
| $0.05^\circ$ | 17 | 34 / 68 | 31 |
| $0.10^\circ$ | 67 | 134 / 268 | 121 |

每次检查还需回传两个角度均值标量。表中的 $K$ 只解决区间宽度条件；实际均值偏离目标时，还需将相应中心代入完整四顶点判据，可能需要进一步调整。它没有保证抽取 $K$ 个样本后必然锁定，更没有把确认成本省略进原六槽无噪声协议。

这个矩形角区间方法具有精确的非线性几何包含关系，但概率上使用了并集上界。局部高斯位置椭圆往往给出更小的样本需求，两者的保守性和近似条件不同，不能把各自最小样本数拼成同一个保证。结果见 [gaussian_confidence_budget.csv](../../outputs/q2/calibration_budget/gaussian_confidence_budget.csv)。

## 6. 实际验证

```bash
conda run -n agent python -m scripts.q2.calibration_budget
conda run -n agent python -m pytest -q tests/q2/test_calibration_budget.py
```

已运行 9 项测试：对称与非对称角区间及零宽度区间的内部位置包含性、顶点达到最大值、有限误差高于一阶值、反求预算单调性、退化区间拒绝，以及单次/多次查看的样本数、最小性与均值标准差缩放。数值测试检查实现；四顶点覆盖整个区间的依据是第 2 节的凸集合推导，联合覆盖概率的依据是第 5 节的高斯区间与并集上界。
