## 代码与复现

[q2.py](../../scripts/q2/q2.py)是自包含方法和分析实现，全部命令见[代码说明](../../scripts/q2/README.md)。三张图由[绘图脚本](../../scripts/q2/build_paper_assets.py)读取既有数据生成，使用项目内中文字体和统一图样式。

```bash
conda run -n agent python scripts/q2/build_paper_assets.py
conda run -n agent python scripts/q2/q2.py protocols --output-dir scratch/q2_reproduction/protocols
conda run -n agent python scripts/q2/q2.py residual --output-dir scratch/q2_reproduction/residual
```

正文编辑源为 `solutions/q2/README.md`；完整推导保存在 `docs/q2/方法推导与模型检验.md` 及各专题。取图时连同图注和图用 CSV 使用，可通过来源清单追溯原始案例。
